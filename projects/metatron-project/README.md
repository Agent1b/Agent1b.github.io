# Metatron Website

Static website concept for the Metatron AI security camera and drone project.

Open `index.html` in a browser. The page uses only local files:

- `index.html`
- `styles.css`
- `script.js`
- `assets/metatron-hero.png`

The content is based on the sibling `../metatron-drone_version` project and presents Metatron as cross-platform AI surveillance software for Linux, Windows, macOS, and Raspberry Pi edge hardware: camera surveillance, YOLO detection, face recognition, plate OCR, evidence recording, Telegram alerts, and E88/WiFi-UAV drone mission controls.
